# QA Standard

QA proves a claim. Start by stating the claim and the smallest validation that can prove it.

## Validation Ladder

- Inspect changed files.
- Run targeted tests.
- Run typecheck or lint when relevant.
- Run build or smoke checks for integration surfaces.
- Inspect rendered or generated artifacts when output quality matters.

## Reporting

Report:

- commands run;
- relevant pass/fail evidence;
- checks skipped and why;
- remaining risk.

# Workflow Taxonomy

## Bootstrap

Create or refresh project instructions, commands, conventions, and memory structure.

## Analyze

Read-only investigation that returns evidence, confidence, and recommended next steps.

## Plan

Convert a goal into scope, acceptance criteria, risks, and validation shape.

## Implement

Make focused code or document changes that match the plan.

## Review

Inspect work for defects, regressions, risks, and missing tests.

## QA

Run or inspect the evidence needed to prove the claim.

## Ship

Prepare final state for commit, PR, release, or handoff.

## Learn

Capture durable memory and skill improvement candidates.

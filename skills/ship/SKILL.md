# Ship

Use this skill after implementation and QA are substantially complete.

## Workflow

1. Inspect current diff and status.
2. Confirm validation evidence.
3. Check for unrelated changes.
4. Prepare concise release or PR notes.
5. Commit only when explicitly requested.
6. Record known gaps and follow-ups.

## References

- `templates/RUN_REPORT.md`

## Outputs

- Delivery summary.
- Validation evidence.
- Deferred work.
- Optional commit or PR notes.

## Stop Condition

Stop when the work is ready for the requested delivery surface or the missing gate is explicit.

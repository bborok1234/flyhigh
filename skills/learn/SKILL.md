# Learn

Use this skill after a task produces durable knowledge.

## Workflow

1. Identify facts worth remembering.
2. Exclude transcripts, secrets, and temporary hypotheses.
3. Update `.flyhigh/memory/` entries if present or create them when useful.
4. Record failed approaches and rejected alternatives.
5. Suggest skill changes only when backed by evidence.
6. Keep memory compact.

## References

- `references/memory-schema.md`
- `docs/eval-and-memory.md`

## Outputs

- Memory updates.
- Skill improvement candidates.
- Evidence for each durable note.

## Stop Condition

Stop when durable facts are captured without bloating future context.

# Review

Use this skill to find problems before summary.

## Workflow

1. Determine review scope.
2. Inspect relevant diff and affected code paths.
3. Look for bugs, regressions, risks, and missing tests.
4. Lead with findings ordered by severity.
5. Include file and line references where possible.
6. If no issues are found, state residual risk and test gaps.

## References

- `references/code-review-standard.md`

## Outputs

- Findings first.
- Open questions.
- Short summary only after findings.

## Stop Condition

Stop when review findings are grounded in inspected evidence.

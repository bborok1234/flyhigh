# Analyze

Use this skill when the next best action is understanding, not editing.

## Workflow

1. State the question and expected evidence.
2. Search for relevant files, symbols, commands, docs, and tests.
3. Read only the files needed to answer the question.
4. Separate evidence from inference.
5. Rank findings by confidence and impact.
6. Recommend the smallest next step.

## References

- `references/workflow-taxonomy.md`

## Outputs

- Evidence-backed synthesis.
- File references.
- Confidence levels.
- Open questions or blockers.

## Stop Condition

Stop when the question is answerable with concrete evidence or when the missing evidence is explicit.

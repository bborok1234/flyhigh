# Plan

Use this skill before broad or risky implementation work.

## Workflow

1. Restate target result, constraints, non-goals, and stop condition.
2. Inspect current implementation enough to avoid fantasy architecture.
3. Draft PRD and test-spec artifacts when useful.
4. Identify risks, tradeoffs, and rejected alternatives.
5. Define validation evidence before editing begins.

## References

- `references/engineering-principles.md`
- `templates/PRD.md`
- `templates/TEST_SPEC.md`
- `templates/DESIGN.md`

## Outputs

- Plan summary or project-local artifacts.
- Acceptance criteria.
- Validation plan.
- Risks and unresolved questions.

## Stop Condition

Stop when implementation can proceed without unresolved material ambiguity.

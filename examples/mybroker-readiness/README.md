# Domain Project Readiness Example

This fixture demonstrates that a future domain project can install Flyhigh without placing domain-specific logic in the Flyhigh core.

Expected installation outputs:

- project instructions;
- `.flyhigh/memory/`;
- `.flyhigh/domain-skills/`;
- `reports/runs/`;
- optional project dashboard state.

Domain-specific skills should live in the target project, not in Flyhigh.

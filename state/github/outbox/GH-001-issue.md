# 대시보드 rollup과 오래된 카드 정리

## 왜 필요한가

작업판이 커질수록 운영자가 진행 중인 카드, 완료 카드, 반복 로그를 빠르게 구분할 수 있어야 한다.

## 본문

## 목적

Flyhigh dashboard가 많은 이슈와 반복 로그를 다룰 때도 운영자가 빠르게 판단할 수 있게 한다.

## 수용 기준

- 상태별 요약 지표가 보인다.
- 완료 항목은 접거나 축약할 수 있다.
- 최근 반복 로그와 검증 결과가 먼저 보인다.
- GitHub 운영 보드와 기존 작업 칸반이 같은 SSOT에서 렌더링된다.

# Basic Node Repo Bootstrap Rubric

The bootstrap output passes when:

- `AGENTS.md` is created.
- `.flyhigh/bootstrap-report.md` is created.
- `.flyhigh/memory/` contains the six standard memory files.
- Stack includes JavaScript/TypeScript, React, Vite, and TypeScript.
- Commands include `pnpm dev`, `pnpm test`, `pnpm build`, `pnpm lint`, and `pnpm typecheck`.
- Important directories include `src`.
- The output does not include domain-specific business logic.
